# Crash Factor and Temporal Analysis

## Purpose

This analysis examines how crash frequency and serious crash outcomes
vary over time and across crash characteristics recorded by NCDOT.

A serious crash is defined as severity K (fatal) or A
(serious/disabling injury).

The primary severity metric is the number of K+A crashes per 1,000
recorded crashes with known severity.
